# ماسح جان الفلكي

ماسح تداول يطبّق أدوات و. د. جان على السعر والزمن، ويحوّل مواقع الكواكب إلى أسعار، ويُطلق إشارة صفقة عندما **يلمس السعر خط كوكب في نفس اللحظة التي يتربع فيها السعر مع الزمن**. يعمل من أي متصفح أو هاتف، ويُثبَّت كتطبيق (PWA).

> أداة بحث وتعليم وليست توصية مالية. لا يوجد دليل علمي منشور على القدرة التنبؤية لأساليب جان أو التنجيم المالي، ولهذا يقيس الماسح كل قاعدة على بياناتك ويعرض النتيجة كما هي.

## ما بداخله

| المجموعة | الأدوات |
|---|---|
| السعر | مربع التسعة، زوايا جان (8×1 … 1×8)، تقسيم المدى (أثمان وأثلاث)، المربعات الطبيعية، مربع 144، الخطوط الفلكية |
| الزمن | الدورات الثابتة، مربعات الزمن، الذكرى السنوية، التواريخ الموسمية، تربيع السعر بالزمن |
| الفلك | الأوجه بين الكواكب، التراجع والاستقامة، دخول البروج، المحاق والبدر (أرضي أو شمسي المركز) |
| السعر (جديد) | زاوية زمن الكوكب (السعر يتحرك درجة لكل درجة يقطعها الكوكب)، صندوق جان 52/90/144/360 |
| الزمن (جديد) | أرباع وأثمان صندوق جان، السعر ÷ 10 أو 100 كعدد أيام |
| الاتجاه | مخطط التأرجح ذو الشمعتين |
| الصفقات (قواعد جان) | الدخول: قاع/قمة مزدوجة أو ثلاثية، ارتداد 3/8–5/8 مع الاتجاه، كسر آخر قمة/قاع على مخطط التأرجح. الوقف تحت القاع المبني عليه ثم يُرفع تحت كل قاع تأرجح جديد (أو هدف ثابت). الدرجة A/B/C من تأكيد الزمن (دورات، ذكرى سنوية، مواسم، مربعات، أوجه، السعر = الزمن) وتأكيد السعر (مربع ٩، أثمان، زوايا، خطوط الكواكب) عند القاع/القمة |
| التحقق | اختبار تاريخي بلا نظر للمستقبل لكل استراتيجية مقابل الصدفة (مع p-value)، ومحاكاة صفقات بالـ R |

الرسم مبني على Lightweight Charts من TradingView وبنفس تخطيط TradingView: شريط علوي (الرمز، الفريم، نوع الرسم، المؤشرات، الإعادة، التنبيه، لقطة، ملء الشاشة)، شريط أدوات رسم يسار (تحديد وحذف، خط اتجاه، شعاع، أفقي، رأسي، مستطيل، فيبوناتشي، مروحة جان، صندوق جان، قياس السعر والزمن، مغناطيس)، أسطورة بأزرار إظهار/إخفاء، شريط سفلي (1M…All، ساعة UTC، % و log و auto)، أنواع رسم (شموع، مفرغة، OHLC، هايكن آشي، خط، مساحة)، واختصارات Alt+T/H/V/F/R/G/M وDelete وCtrl+Z.

## مصادر البيانات

| الأصل | التاريخ (الشموع) | السعر اللحظي | مفتاح؟ |
|---|---|---|---|
| الذهب والفضة (XAU/USD, XAG/USD) | Twelve Data، مبنية على جلسة نيويورك مثل TradingView | مؤشر Binance للذهب/الفضة كل ثانية (WebSocket)، مُعايَر على سعر Twelve Data الفوري | نعم (Twelve Data فقط) |
| العملات الرقمية (BTC/USD, ETHUSDT …) | Binance | Binance WebSocket لحظي | لا |
| العملات والأسهم وصناديق ETF | Twelve Data | كل دقيقة | نعم |
| داخل claude.ai | موصل Twelve Data في حسابك | حسب الموصل | لا |

### مطابقة TradingView
- شموع الذهب والفضة والعملات (4 ساعات، يومي، أسبوعي) تُبنى من شموع الساعة على **جلسة نيويورك 18:00 → 17:00** مثل OANDA:XAUUSD على TradingView: مساء الأحد يدخل في شمعة الإثنين، وشموع الأربع ساعات تبدأ 18:00 نيويورك، والتوقيت الصيفي محسوب تلقائيًا.
- شموع 15 دقيقة والساعة والعملات الرقمية على توقيت UTC مثل TradingView.
- السعر نفسه قد يختلف بسنتات عن TradingView لأن كل منصة تأخذ من مزود مختلف.

### حدود Twelve Data المجاني
800 طلب في اليوم. الماسح يعدّ الطلبات، ويحدّث الذهب رسميًا كل 15 دقيقة فقط (السعر اللحظي من Binance لا يستهلك رصيدًا)، ويتوقف عند غلق السوق وعند إخفاء الصفحة.

## الدقة

كل شيء محسوب بتوقيت UTC، ومواقع الكواكب بمكتبة Astronomy Engine. الاختبارات (`npm test`) تقارنها بمكتبة مستقلة (astronomia: VSOP87 وELP):

| الاختبار | النتيجة |
|---|---|
| أطوال الكواكب الشمسية المركز، 41 تاريخًا 1950–2050 | أكبر فرق 0.0052° |
| أطوال الكواكب الأرضية المركز (مع زمن الضوء) | أكبر فرق 0.0047° |
| طول القمر | أكبر فرق 0.0025° |
| اقتران المشتري وزحل 2020-12-21 | ضمن 7 دقائق |
| الاعتدال الربيعي 2024، محاق كسوف 8 أبريل 2024، توقف عطارد 1 أبريل 2024 | ضمن دقيقة واحدة |

وأيضًا: رياضيات مربع التسعة، قراءة ملفات CSV بصيغها، **عدم استخدام المستقبل** (القمم والقيعان والإشارات على بيانات مقطوعة تطابق البيانات الكاملة)، ومحاكاة الصفقات المتحفظة.

بخط كوكب عند معامل 1 دولار للدرجة، فرق 0.005° = نصف سنت على السعر.

## التشغيل محليًا

```bash
npm install      # للاختبارات فقط
npm test
npm run serve    # http://localhost:8080
```

لا توجد خطوة build: الموقع ملفات ثابتة.

## النشر على GitHub Pages

1. ارفع الريبو على فرع `main`.
2. Settings ← Pages ← Source: **GitHub Actions**.
3. كل push يشغّل الاختبارات أولًا، ولو نجحت ينشر الموقع على `https://<user>.github.io/<repo>/`.
